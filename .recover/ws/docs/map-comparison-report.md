# 王者峡谷 标准地形 vs HonorKing 现地图 —— 对比分析报告

> 依据：`scripts/core/BattleManager.gd` 中 `_create_map()` / `_create_turrets()` / `_create_jungle()` / `_generate_*_walls()` 的实测数据；标准侧按《王者荣耀》5v5 王者峡谷的公开结构描述。
> 结论先说：**拓扑是对的，差距不在"像不像三条路"，而在高差、节奏参数、地形包边和一处经济不对称 bug。**

---

## 0. 结论摘要

| 判定 | 内容 |
|---|---|
| ✅ 结构正确 | 180° 中心对称、三条分路（两条 L 形边路 + 对角中路）、河道与中路垂直、双龙坑在河道上且对角对称、每队 10 座建筑（9 塔 + 水晶） |
| ⚠️ 参数偏离 | 暴君/主宰首次刷新 **4:00**（标准 2:00）；河灵在角落（标准在河道中段）；空间之灵 60s（标准 30s 左右） |
| ⚠️ 地形缺失 | **全图无高差**（高地 +0.2、河道 +0.02、分路 +0.05，本质都在 y≈0），河道不凹、高地不抬、没有地形遮挡与开团地形 |
| ⚠️ 形体粗糙 | 分路=L 形矩形、高地=四分之一圆盘、野区=栅格墙片、草丛=≈95 个点串成的"草墙"；缺 HoK 的连续石墙、包边、成簇草丛 |
| ❌ 真 bug | 镜像野怪类型不一致（`pig` vs `pig_small`、`lizard` vs `lizard_big`），`_materialize_jungle_group()` 没有这两个分支 → **两边同位置野怪金币/经验/魔抗不同** |

## 1. 标准王者峡谷的 8 个结构要素

1. 正方形地图，蓝方左下、红方右上，**180° 旋转对称**（所有塔、野怪、草丛镜像成对）。
2. 三条分路：**对抗路**（沿左上两条边的 L）、**中路**（左下→右上对角线）、**发育路**（沿右下两条边的 L）。
3. **河道**沿另一条对角线（左上角 ↔ 右下角）穿过中心，与中路**垂直**相交；交叉处是开团核心区。
4. 河道上两处坑：**主宰**（左上河道）、**暴君**（右下河道），对称分布。
5. 每队 **9 座塔**（每路 外塔/二塔/高地塔）+ **水晶**，水晶后为泉水；高地是**抬高的平台**，三路各留缺口。
6. 每方野区两片（红区/蓝区），标配 红BUFF、蓝BUFF、山豪(3)、暗影狼(2)、烈雉、魔种蜥蜴等，**由连续墙体和窄口围成隔间**，隔间之间有草丛做视野博弈。
7. 史诗节奏：暴君/主宰 **2:00** 首刷 → 10:00 暗影暴君/暗影主宰 → 20:00 风暴龙王；河道之灵更早、靠河道中段。
8. 高地—野区—河道之间有明显**高差**，草丛约 19~20 处成片分布。

## 4. 问题清单（按影响排序）

### P0-1 镜像野怪经济不对称（真 bug，2 行修复）
`_create_jungle()` 用 `pig` / `lizard` 给蓝方，用 `pig_small` / `lizard_big` 给红方，但 `_materialize_jungle_group()` 的 `match type` 里**没有这两个分支**：
- 红方山豪走默认金币/经验，且 `magic_resist: 0`（蓝方是 90）；红方蜥蜴同理
- 结果是同一位置的野怪，两边打野收益和击杀速度不一致

修法（`BattleManager.gd` 约 L848 的 match 里加两行）：
```gdscript
"pig_small":
    cfg["kill_gold"] = 45; cfg["kill_exp"] = 32
"lizard_big":
    cfg["kill_gold"] = 42; cfg["kill_exp"] = 30
```
（更彻底的是统一命名，让镜像营地用同一个 type。）

### P0-2 龙坑 4:00 才刷（节奏偏离标准）
标准 2:00 首刷。项目阶段 0 是 4:00–9:30，导致前 4 分钟没有中立资源争夺点，打野前 3 分钟的路线价值被削弱。
修法：改 `epic` 首刷常量 + 阶段 0 时间窗（约 5 行），需同步公告文案/音效时点。

### P0-3 全图无高差（最影响"像不像峡谷"）
现在高地、分路、河道、野区几乎同一平面。标准峡谷的高差带来三件事：高地视野优势、河道开团地形、野区窄口卡位。
- 低成本（~1h，纯视觉，不改玩法）：野区加 ±0.3 噪声起伏（shader 顶点位移）+ 高地边缘做挡土墙/台阶模型 + 河道岸边石墙 + 河道整体压暗 0.5 单位；单位仍然踩 y=0，不破坏 AI/射线。
- 高成本（半天+，真高差）：地面高度场 + 实体贴地 + 射线命中点 + 小地图/寻路同步，属于结构性改造。

### P1-1 草丛形态（≈95 点 → 成簇）
现在草丛是沿直线每 1.4 单位一个点，视觉是一堵"草墙"。标准是 19~20 处成片草丛。
低成本修法（~15 行）：把现有点位按"间距 > 6 归新簇"聚类，每簇保留中心 + 随机 3~5 个偏移点，删除多余点 → 立刻接近标准观感，且实际阻挡/视野判定逻辑不变（Bush 数量可保持）。

### P1-2 高地形体
圆盘 → HoK 那种"圆角平台 + 直角挡土墙 + 三路开口"。用 `CSGPolygon3D` 把当前 `_create_fan_plane()` 的多边形改为 2 段直边 + 圆弧过渡即可（~25 行），塔/泉水坐标不用动。

### P1-3 河灵位置
现在放 (±58,±58) 两角，标准在河道中段靠近两侧草丛。改两个坐标即可（2 行），但会改变打野前 90 秒路线，建议与平衡一起调。

### P2 细节
- 分路 L 转角（+55,+55 / −55,−55）没有转角铺装/墙包边，兵线视觉上是直角硬拐。
- 野区墙是 2 单位一片的独立墙片，接缝处有缝；改成连续墙或直接贴地形。
- 地图边界靠雾遮挡，可加一圈山体/云海网格。
- 无视野机制（`_ready()` 里"视野管理器"仍是空注释），草丛只有判定没有迷雾。

## 5. 如果只做三件事（推荐顺序）

1. **修镜像野怪 bug**（2 行，立刻消除经济不对称）
2. **草丛成簇**（15 行，视觉最接近标准、零玩法风险）
3. **低成本高差/包边**（1 小时，纯视觉：野区起伏 + 高地挡土墙 + 河岸石墙）

龙 2:00 与河灵位置属于**平衡改动**，建议单独一轮做，避免和视觉改动混在一起不好回归。
