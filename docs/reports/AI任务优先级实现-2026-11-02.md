# AI 任务优先级实现

实现时间：2026-11-02

## 一、改造前

`TeamTask.priority` 只是元数据：

- 生成任务时写入；
- 没有任何代码读取比较；
- 真正顺序由 `if/continue` 硬编码决定；
- `assign_team_task()` 无条件覆盖旧任务。

## 二、改造后

### 1. 团队层按 priority 选择

团队层判断顺序改为：

```text
DEFEND_LANE      100
PUSH_TOWER        90
INVADE_JUNGLE     85
OBJECTIVE         80
正常分推
```

### 2. 任务生成按 priority 覆盖

`_make_task_for()` 顺序：

```text
DEFEND_LANE      100
PUSH_TOWER        90
INVADE_JUNGLE     85
OBJECTIVE         80
GANK              70
PUSH_LANE/JUNGLE  50
PEEL              50
```

### 3. 英雄接任务时比较 priority

`HeroAI.assign_team_task()`：

- 新任务优先级低于当前任务 → 拒绝，保留当前任务；
- 新任务优先级高于当前任务 → 立即抢占；
- 同优先级 → 2 秒承诺窗口内不切换；
- 窗口结束后同优先级可切换。

### 4. 重规划不再清空旧任务

`TeamTactics._finish_task(REASSIGNED)`：

- 只标记旧任务为 REASSIGNED；
- 不再立刻清空 HeroAI 手上的当前任务；
- 让 `assign_team_task()` 按 priority 决定是否抢占；
- 旧任务保留到过期/完成/失败。

### 5. 生存层仍然最高

HeroAI 决策顺序不变：

```text
本线塔防御 → 回城 → 低血撤退 → 换血 → 临时清兵
→ TeamTask → LaneStrategy/JungleStrategy
```

任务 priority 只用于任务之间抢占，不会压过生存和换血。

## 五、注意

- 高优先级任务在承诺窗口内也可以抢占；
- 低优先级任务即使目标更近，也不能覆盖当前高优先级任务；
- 同优先级才会使用承诺窗口；
- 生存/回城仍然压过所有团队任务。
