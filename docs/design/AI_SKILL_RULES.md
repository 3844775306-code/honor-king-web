## 1. 总时序

### 每帧
1. 推进连招链；
2. 残血追击：追击中先尝试位移贴脸，再在10m内放技能；
3. 检查恢复（CD 好、血/蓝低于阈值即可用）；
4. 处理撤退/安全回城；
5. 有锁定目标且在技能入口距离内 → 尝试技能。

### 每个 think tick（线上 1.0s / 打野 0.5s，低难度有概率跳过）
1. 英雄特判窗口（李白 Q、太乙 Q 等）；
2. 召唤师技能；
3. 主动装备；
4. 决策、升级、赶路位移。

## 2. 英雄技能

### 2.1 通用入口条件

普通目标：
- 目标有效且未死亡；
- 与目标距离 `< SKILL_USE_RANGE = 10m`；
- `skill_feed_timer <= 0`（每次起新技能/连招后 0.5 秒内不再起新技能）。

防御塔：
- 默认所有英雄**禁止对防御塔释放技能**；
- 例外：刘禅允许对塔放技能（`LiushanBrain.can_cast_on_turret()`）。

英雄特判：
- 后羿 3 技能（大招）只对英雄释放，不打小兵/野怪/防御塔。

> 当前技能层不额外判断目标优先级（塔除外），目标由 HeroAI 决策层给出。

### 2.2 连招规则

先尝试连招；所有连招都不可用时，退回单技能评分。

连招必须满足：
- 连招中每个技能：已学习、CD=0、蓝量足够、英雄特判允许（`brain.can_cast_on`）；
- 目标为防御塔时，仅刘禅可用。

默认连招由英雄自己的技能构成自适应生成（`HeroBrain.get_combos`）：

1. **起手技能排序**：控制（眩晕/击飞/减速）> 位移 > 增益 > AoE，按 `_combo_setup_score` 降序；
2. **大招**：如果大招带起手价值（控制/位移/增益/AoE），参与起手排序；否则放到连招最后作为终结技；
3. **其余伤害技能**：按技能伤害从高到低接在起手技能后；
4. 生成 `adaptive_burst`，优先级按职责：刺客 0.70 / 战士 0.60 / 法师 0.55 / 射手 0.50 / 辅助 0.45；
5. 另外生成 `adaptive_poke`：所有有伤害的技能，按施法距离从远到近，优先级 0.30。

具体英雄由下方英雄专用连招覆盖；未列出的英雄使用上述自适应规则。

> 连招中的大招同样执行“附近无敌方英雄则不用”的门槛；小兵打塔例外不适用于后羿（后羿大招只对英雄）。

连招起手后：
- 段间等待 = `max(技能前摇, COMBO_STEP_GAP=0.35s)`；
- 中途目标失效、目标变化、被控、施法/引导中、距离 >10m、技能条件不满足 → 连招中止；
- 连招中止后回到常规决策。

### 2.3 单技能评分

没有可用连招时，对每个可用技能评分，取分数最高且 >0 的技能。

| 条件 | 加分 |
|---|---:|
| 基础分 | +1.0 |
| 有伤害 | +min(伤害/500, 2.0) |
| AoE（type=1），范围内每有 1 个敌方英雄 | +0.5 |
| 增益（type=2），范围内每有 1 个敌方英雄 | +0.5 |
| 带控制效果的技能，附近每有 1 个友方英雄 | +0.5 |
| 护盾（type=6），自身 HP<50% | +1.0 |
| 大招，半径内没有敌方英雄 | 强制不使用；除非目标是敌方小兵、正在攻击我方防御塔且 HP>1000，此时 +min(附近敌方小兵总血量/2500, 2.0)。后羿不吃这个例外，只对英雄 |
| 大招，半径内每有 1 个敌方英雄 | +1.0 |
| 难度随机扰动 | ±`score_random × max(|分数|,1)` |

说明：
- 技能“半径”= `skill.radius>0 ? radius : (cast_range>0 ? cast_range : 8m)`；
- 控制效果 = `applies_stun>0` 或 `applies_knockup>0` 或 `applies_slow>0`；
- “附近敌方小兵总血量”统计目标小兵周围 `max(技能半径, 塔攻击范围)` 内的敌方小兵。

难度随机幅度：
- 青铜 0.30、白银 0.20、黄金 0.12、铂金 0.08、钻石 0.05、王者 0.02。

单技能释放后同样设置 `skill_feed_timer = 0.5s`。

### 2.4 瞄准与难度

- 铂金以上按预判帧提前量：`目标位置 + 速度 × 0.05 × 预判帧`；
  - 青铜/白银/黄金 0 帧；铂金 1 帧；钻石 2 帧；王者 3 帧。
- 落点误差半径 = `(1 - skill_accuracy) × 3m`，随机方向；
  - 青铜 0.55 → 约 1.35m；
  - 白银 0.72 → 约 0.84m；
  - 黄金 0.88 → 约 0.36m；
  - 铂金 0.95 → 0.15m；
  - 钻石/王者 1.0 → 0。

### 2.5 英雄特判/强制施放

| 英雄 | 规则 |
|---|---|
| 后羿 | 3 技能只对英雄释放 |
| 刘禅 | 允许对防御塔放技能 |
| 李白 | Q 窗口期内且 5m 内有敌人 → 强制二段 Q |
| 太乙真人 | Q 窗口剩余 <0.5s → 引爆 |
| 兰陵王 | 4 技能隐身 CD 好、12m 内有敌人且状态 PUSH → 强制隐身 |
| 孙悟空 | 回城安全由 `WukongBrain.handle_recall_safe` 处理，不属于技能施放 |

英雄专用连招：

| 英雄 | 连招（槽位顺序，优先级） |
|---|---|
| 兰陵王 | 4→0→1→2 (0.95，隐身或4技能可用)；0→1→2 (0.7)；4→2→1→0 (0.85，8m内且目标 HP<40%) |
| 李白 | 1→0→2 (0.9 若自身 HP<50%，否则 0.5)；0→1 (0.7，8m内)；2→1→0 (0.6) |
| 太乙真人 | 0→1 (0.85)；1→0 (0.75，5m内)；2→0→1 (0.9 若自身 HP<30%，否则 0.2) |
| 其余英雄 | 使用英雄自适应连招（见 2.2） |

> 当前 `modify_skill_score()` 在英雄 brain 中定义但没有被 `SkillTactics` 调用，所以“技能偏好加分”暂不生效。

### 2.6 位移/加速技能额外触发

- 赶路位移：只要 `move_target` 距离 > 普攻距离（`attack_range*0.01`）就尝试使用位移技能；
- 不再限制只在 PUSH/FARM、不再限制 9m 最小距离、不再因附近有敌人/敌塔而完全禁用；
- 施法/受控/回城/传送/有锁定目标时不触发赶路位移；
- 落点仍做可站立/敌塔射程校验（`_resolve_dash_end`）；
- 当前可自动用于赶路的是位移技能（type=4 / `self_displacement>0`）和强普位移；纯移速增益技能没有通用字段，暂不自动用于赶路；
- 闪现只用于追击/逃跑，不用于赶路（`_try_flash_travel` 不再被调用）。

## 3. 召唤师技能

每个 think tick 检查一次，召唤师技能 CD 必须为 0。

| 召唤师技能 | 触发条件 |
|---|---|
| 治疗术 | 自身 HP < 40% |
| 传送 | ① 状态 PUSH、80m 内有友方塔、30m 内有敌方塔且英雄距其 >40m；或 ② HP<50%、80m 内有友方塔、8m 内敌人 ≥2 |
| 疾跑 | 追击/逃跑 |
| 狂暴 | 换血窗口 |
| 净化 | 被眩晕，或减速时间 >1s |
| 弱化 | 换血窗口 |
| 终结 | 5m 内最近敌方英雄 HP<20% |
| 闪现 | ① 逃跑时反向闪；② 追击时向敌人闪（距离>5m 才闪，不浪费） |
| 惩击 | 最近野怪 HP < 1500 + 等级×100 |

判定定义：
- **追击**：状态 PUSH 且 8m 内有敌方英雄；
- **逃跑**：状态 RETREAT / RECALL_SAFE，或 HP<50% 且 6m 内有敌方英雄；
- **换血窗口**：`TradePlanner.active_target` 有效（没有 planner 时用 PUSH + 5m 内敌英雄兜底）。

闪现落点必须可站立；可穿墙，最大 5m。

## 4. 恢复

恢复技能位于技能槽 4（普通技能候选不包括该槽）。

每帧检查：
- 恢复技能 CD=0；
- 自身 HP < 70%，或有蓝英雄蓝量 < 70%（张飞除外，张飞不看蓝）；
- 蓝量足够支付恢复技能消耗；
- 满足则直接施放恢复。

泉水养伤（非恢复技能，但相关）：
- 一般英雄 HP 与蓝量都回到 98% 才离泉；
- 孙悟空必须 100%；
- 张飞只看 HP。

## 5. 主动装备

每个 think tick 按固定顺序检查；装备必须已购买且 CD=0。满足条件可能同一 tick 连续触发多个。

| 主动装备 | 触发条件 | CD |
|---|---|---:|
| 净化 | 5m 内敌人 ≥2，且自身 HP<50% | 75s |
| 金身 | 5m 内敌人 ≥1，且自身 HP<20% | 75s |
| 血怒/狂暴之魂 | 自身 HP<30% | 75s |
| 逐日之弓/迅捷长弓 | 状态 PUSH、10m 内有敌方英雄 | 75s |
| 反伤刺甲 | 5m 内敌人 ≥2 | 75s |
| 冰霜冲击/凛冬 | 5m 内敌人 ≥2 | 75s |
| 幽影袖箭 | 自身 HP<30%、8m 内敌人 ≥1 | 60s |

## 7. 当前实现限制

1. **没有 per-skill 任意条件配置**：目前只能通过连招顺序、评分权重、`brain.can_cast_on()`、`brain.can_cast_on_turret()`、`process_skill_windows()` 控制。若要“某英雄某技能只在某条件下放”，需要新增条件字段/代码。
2. **没有按技能自身 cast_range 过滤**：统一只检查与目标距离是否 <10m；小射程技能可能在 10m 入口被选中，需要的话应补按 cast_range 过滤。
3. **modify_skill_score 未接入**：英雄 brain 里的评分偏好当前是死代码。
4. **恢复已从普通技能候选排除**，只由 `_try_use_recover()` 独立处理。
