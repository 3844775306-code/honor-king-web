# 法术动画（VFX）优化方案 · 待确认

> **实施状态（2026-10-29）**：方案已确认（全量 P0→P3 / 只做视觉前摇 / 联机双端一致）。
> **P0 底座已实施**：见文末「七、P0 实施记录」。P1（17 个大招/机制技能）起待复核 P0 观感后继续。

> 目标：让 28 个英雄 × 3 个技能、9 个召唤师技能、普攻/受击/状态特效「看起来像真的在施法」。
> 本方案**只改视觉与动作层**，不改伤害、冷却、判定与数值时序（唯一例外见「待确认项 2」）。
> 确认后按第五节的 P0→P3 批次实施，每批可独立验收、可随时停。

## 一、现状体检（为什么现在看起来假）

| # | 问题 | 代码证据 |
|---|---|---|
| 1 | **施法没有身体动作**。英雄 GLB 自带 30 个动画切片（idle/walk/sprint/jump/fall/crouch/holding-both-shoot/attack-melee/attack-kick/interact/emote/die…），实际只用了 `idle`、`walk`、`attack-melee-left`、`die` 四个 | `Hero.gd:4129`、`Hero.gd:1509`、`Hero.gd:2508`、`GameEntity.gd:1152` |
| 2 | **远程英雄普攻也播近战挥砍**（`_play_anim("attack-melee-left")` 在远程子弹分支之后无条件调用），法师/射手原地挥拳 | `Hero.gd:2401-2508` |
| 3 | **走路的 walk 动画每帧被 `play()` 重置**（`_play_anim` 只判断 has_animation 后直接 play），疑似永远卡在第 0 帧 | `Hero.gd:1509` + `GameEntity.gd:1181-1183` |
| 4 | **技能零前摇零后摇**：`skill.cast_time` 字段存在但全项目无人读取；`_start_casting()` 只记 target，下一帧 `_finish_casting()` 立即结算并生成弹道 | `Skill.gd:12`、`Hero.gd:3145-3161`、`Hero.gd:3359` |
| 5 | **特效全是 primitive + Tween**：球/柱/环/方块 + 半透明无光照材质 + 缩放淡出；全项目 0 个 `GPUParticles3D`、0 个 `.gdshader`、0 张特效贴图 | `SkillDataBase.gd` 全文、`MeshFactory.gd`、`Bullet.gd:110-118` |
| 6 | **弹道模型与技能无关**：所有英雄/技能弹道统一用弓箭/子弹/石块 GLB，法师火球也是箭；只有甄姬水球、妲己爱心、小乔扇子临时覆盖 | `Bullet.gd:64-120`、`SkillDataBase.gd:543-547/1100-1110/1154-1169` |
| 7 | **命中无反馈**：`take_damage()` 不产生闪白/火花/顿帧/震屏；全项目搜不到 `shake/hitstop/Engine.time_scale`，屏幕层只有伤害飘字 | `GameEntity.gd:587`、全局 grep |
| 8 | **状态无视觉**：护盾只有 UI 条没有护盾球；眩晕/沉默/压制/减速/霸体/无法选中几乎没有画面信号；蓄力（太乙Q、张飞Q、沈梦溪W、安琪拉R）只有数值 | `GameEntity.gd:83-84`、`Hero.gd:1585` |
| 9 | **大招和普通技能同质**：除了范围/颜色/时长没有镜头、光、地裂、慢镜等「大招感」；持续区域只是一个半透明圆盘（暴风雪=圆盘、水域=圆盘+环），没有粒子流 | `SkillDataBase.gd:1645-1660`、`2567-2605` |
| 10 | **联机特效是白名单**：host 只广播 12 种 `FX_*`，client 端有对应 catalog；新特效若只做本地，client 看不到敌方技能 | `NetSession.gd:156-168`、`NetClientBattle.gd:52-62` |

**结论**：真实感的关键不是粒子数量，而是五件事——① 有前摇/命中/后摇的时间结构；② 施法者的身体与手在动；③ 光与地面有交互；④ 命中有物理反馈；⑤ 同元素材质/拖尾/配色一致。下面按这个顺序改造。

## 二、总体架构（6 个模块，先搭底座再填技能）

新增文件（约 700-900 行）：

| 模块 | 文件 | 内容 |
|---|---|---|
| A. VFX 工厂 | `scripts/core/VfxFactory.gd`（autoload `Vfx`） | 预设化粒子/光束/冲击环/地面贴花/闪光/拖尾/命中火花；对象池 + 并发上限 + 移动端质量档；所有方法返回可复用句柄，双端（host/client）一致 |
| B. FX 材质/着色 | `shaders/fx_glow.gdshader`、`fx_beam.gdshader`、`fx_decal.gdshader`、`fx_dissolve.gdshader` | 软边径向渐变、加色混合、沿轴 UV 流动、噪声腐蚀淡出；贴图用 `GradientTexture2D`/`NoiseTexture2D`/`CurveTexture` **程序生成**（不引入美术资源） |
| C. 动作状态机 | 改 `scripts/entities/GameEntity.gd` + `Hero.gd` | `_play_anim` 改为状态机（idle/walk/run/cast/attack/hit/die/channel/transform），同状态不重启；新增 `_cast_anim(skill)` 按技能形态选 clip |
| D. 镜头/画面反馈 | 改 `scripts/core/BattleManager.gd` + `UI_Manager.gd` | `shake()`（叠加在 `cam_pan_offset` 后）、`hitstop()`（30-50ms）、`fov_punch()`、屏幕闪白/暗角层（仅本地表现，不同步） |
| E. 元素风格库 | `VfxFactory` 内 `ELEMENTS` 常量 | 火焰/冰霜/水流/雷电/暗影/圣光/刀刃/风音/大地 9 套：主色+副色+粒子纹理+拖尾+命中+光源+音键 |
| F. 技能 FX 表 | `assets/SpellFxTable.gd` | `{英雄: {槽位: {element, cast_anim, windup, muzzle, projectile, impact, residue, camera}}}`；`apply_skills` 里的视觉调用全部收口到这里，数值逻辑不动 |

**为什么用表驱动**：现在 `apply_skills` 已 1900 行、视觉代码和伤害逻辑混在一起，逐技能重写会互相踩。表驱动后每个技能只加 5-15 行配置，后续调整不用碰伤害代码，联机 kind 也能统一映射。

## 三、通用层（做一次，全技能受益；P0 内容）

### 3.1 施法动作
按技能形态映射到已有 clip（无需新美术）：

| 形态 | clip | 程序化叠加 |
|---|---|---|
| 近战斩击（吕布/铠/亚瑟/夏侯惇/孙悟空/英睿/张飞/李白） | `attack-melee-left/right` 左右交替、`attack-kick-left/right` | root 前踏 0.15m（ease-out）+ 上身前倾 6° |
| 投射施法（安琪拉/妲己/小乔/甄姬/沈梦溪/王昭君/东皇/太乙/张飞Q） | `holding-both-shoot`、`holding-right-shoot` | 右手骨挂点（`BoneAttachment3D`→`arm-right`）生成手部光球，出手瞬间切到手掌张开 |
| 射手/拉弓（后羿/孙尚香/马可波罗/狄仁杰/李元芳/鲁班/元流） | `holding-both-shoot`（弓）/`holding-right-shoot`（枪） | 后坐力 0.03m + 0.06s 回弹 + 枪口/弓弦闪光 |
| 位移/突进（马超/兰陵王/李白/不知火舞/大禹R2/孙尚香Q） | `sprint`+`jump`/`fall` | 3 段残影拖尾 + 落地烟尘 |
| 蓄力/引导（太乙Q/张飞Q/安琪拉R/王昭君R/刘禅R/东皇R） | `crouch`→`holding-both` | 蓄力球体随时间膨胀 + 地面法阵收缩环 |
| 变身/爆发（张飞R/英睿R/铠R） | `emote-yes` | 模型 `scale` + emission 脉冲 + 光柱 + 地面裂纹 |
| 受击（无 clip） | 程序化 | root 后仰 0.12rad/0.15s + 受击闪白 80ms |
| 死亡 | `die`（已用） | 落地尘 + 灵魂光点上升 |

### 3.2 施法时间轴（前摇/命中/后摇）
- Q/W 视觉前摇 0.12-0.20s，R 0.30-0.50s（与 `Skill.cast_time` 对齐）。
- **默认不改判定时序**：前摇内只播动画+蓄力粒子，伤害仍按现有帧结算；若你选择「真实前摇」（待确认项 2），再把 `_finish_casting` 延后。
- 后摇 0.15-0.30s 只做动作收尾，不锁操作。
- 持续类技能（安琪拉R、王昭君R、小乔R、甄姬R、刘禅R）的**视觉脉冲与伤害 tick 用同一个循环驱动**，杜绝「血在掉、特效不动」。

### 3.3 弹道
- 按 `skill_id`/元素覆盖弹体：火焰球+拖尾、水球+水滴、冰晶+雾、暗影+烟、圣光+光点、飞扇/飞镖/枪/箭各自模型+残影。
- 统一挂 `Vfx.trail()` 拖尾（`local_coords=false`），命中时 `Vfx.hit_spark()`。
- 远程英雄普攻改 `holding-*-shoot`，近战改 `attack-melee-*`。

### 3.4 命中反馈（全局）
- 受击闪白：`material_override.emission` 脉冲 80ms（现有 `_set_node_alpha` 已能遍历网格，复用即可）。
- 命中火花 + 冲击小环（0.15s）+ 目标轻微后仰。
- 大招命中：震屏（amp 0.15 / 0.35s）+ 顿帧 35ms + 屏幕边缘压暗。
- 护盾：半透明球体 + 受击时裂痕闪白。

### 3.5 状态与控制视觉
眩晕=头顶星星；击飞=脚下尘环+滞空拖影；冰冻=冰壳包裹（现有染色升级为网格）；减速=脚下蓝色粘滞环；沉默=头顶禁符；压制=锁链（东皇R）；霸体=金色轮廓；无法选中=半透明残影+微扭曲；加速=脚下风线。

### 3.6 召唤师技能（9 个，成本极低、手感提升大）
闪现=起点残影+终点光环；疾跑=脚下风轨+残影；传送=落地光柱+法阵；治疗=绿色上升光点+受疗者光环；终结=头顶斩击线+暗红闪；狂暴=红色气浪+轮廓光；晕眩=金色冲击环；净化=青白解控爆环；弱化=暗紫压制场。

## 九、P2 实施记录（已完成）

**思路**：剩余 50+ 技能不逐个手写，改为「技能类型 → 形态，元素 → 配色/粒子手感」二维自动分档，新增技能自动生效。

**分档规则**（`SpellFxTable.get_skill_shape`）

| Skill.type | 形态 | 表现 |
|---|---|---|
| 0 指向 | `bolt` | 手口→目标快速光束（≤16 单位）+ 落点火花 |
| 1 区域 | `zone` | 目标地面法阵（半径取 `skill.radius`）+ 延迟扩散环；长引导额外挂蓄力光 |
| 3 直线 | `line` | 手口→目标直线光束 + 落点火花 |
| 4 位移 | `dash` | 起点爆发 + 沿途残影粒子 |
| 6 护盾 | `aura` | 脚下环形蓄力光（配合 P0 护盾泡） |

同形态不同英雄由 `VfxFactory.ELEMENTS` 决定主色/亮色/粒子尺寸/重力/速度 → 火球、冰锥、水波、雷光、暗影手感不同。

**发现并修正的数据特性**

- `SkillDataBase.gd:3625` 把 type 1/3/4 全部标 `is_channeling=true`（实为"非指向"标记），
  P2 初版据此分档导致 104 次技能全落进 channel、zone/line/dash 永远不触发；
  改为纯按 `type` 分档，`is_channeling` 只用于"区域内长引导延长时间"。

**验证**

- 编辑器导入：仅既有 `MiniMap.gd` 大小写告警。
- 无头 AI 对局 3000 帧：**280 次技能施放**，五种形态全部实际命中
  （bolt 48 / zone 41 / line 36 / dash 9 / aura 5），`SCRIPT ERROR / Invalid call = 0`。
- 清理调试后复跑 1800 帧仍 0 错误。

**剩余 P3**：状态类视觉（眩晕/减速/沉默/隐身/护盾已有泡）、联机 FX 事件双端一致、移动端画质档与 LOD、观感调优。
