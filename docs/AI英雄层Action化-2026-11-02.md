# AI 英雄层 Action 化实现（第一阶段）

实现时间：2026-11-02

## 一、已完成

### 1. 删除 State 枚举

- 删除 `HeroAI.State`；
- 删除 `var state`；
- 新增 `AIAction` + `current_action`。

### 2. 新 Action 数据

文件：`ai/AIAction.gd`

包含：

- `ActionType`
- `ActionStatus`
- `PauseClass`
- priority / target / lane / expiry / reason

### 3. 安全动作栈

- 被塔攻击 → `TOWER_ESCAPE`
- 弹道躲避 → `DODGE`
- 两者可以压栈；
- 安全动作结束后恢复原 Action；
- 其它打断不恢复。

### 4. 团队任务暂停规则

- 生存 Action：可暂停团队任务；
- 环境 Action：一条团队任务最多暂停一次；
- 新团队任务重置环境暂停计数；
- 暂停期间延长 `team_task.expires_at`。

### 5. 环境任务接入

已标记为环境 Action：

- 血包
- 临时清兵
- 视野之灵
- 大禹鼎

临时清兵仍保留整条 A* 路线避塔检查。

### 6. 目标安全

新增：

- `_is_target_safe()`
- `_estimate_tower_hits()`
- `_estimate_burst_damage()`

越塔估算：

- 计算目标生命 + 护盾；
- 加入关键技能可用伤害；
- 估算塔伤次数；
- >2 次则判定不安全。

### 7. 闪现

- 赶路不再使用闪现；
- 闪现只在：
  - `FINISH_CHASE` 且目标残血；
  - 血量 <20% 且高威胁。

### 8. 外部模块适配

- `SummonerTactics`
- `ItemActiveTactics`
- `LanlingBrain`
- `HeroBrain.process_special_actions`

均改为接收 ActionType。

## 二、尚未完成

这一阶段是 Action 化的第一版，仍保留部分旧结构：

1. **完整 ActionScheduler 未完成**
   - 当前仍由 `_decide()` 的硬编码顺序选动作；
   - `current_action` 已存在，但还没有“候选 Action 统一排序”；
   - Action 的 complete/failed 生命周期还未全面接管。

2. **统一路径规划未完成**
   - 普通移动仍走 Hero `_avoid_walls()` 的 A*；
   - 传送阵/传送召唤师技能还没有进入路径代价比较；
   - 闪现没有进入路径边。

3. **Hero 自动追击未关闭**
   - 还没有增加 `ai_path_controlled`；
   - 当前 manual_target 仍会触发 Hero 自动追击。

4. **环境任务动作还不完整**
   - 血包只用了原 lane 血包查找；
   - 敌方血包/安全条件尚未完整实现；
   - 大禹鼎/视野之灵只做了环境暂停接入。

5. **Action 完成条件**
   - 目前 Action 主要作为当前行为记录；
   - 还没有每个 Action 的 `is_complete/is_failed` 统一执行。

## 三、验证

- `battle.tscn`、`net_client.tscn`、`replay.tscn`、`lobby.tscn` 均 `ERRS=0`；
- 3 个固定种子基准无脚本错误；
- 4 分钟后团队任务冒烟无脚本错误。

## 四、下一步

1. 增加 `AIAction.is_complete/is_failed`；
2. 把 `_decide()` 改为候选 Action 选择；
3. 增加 `hero.ai_path_controlled`，关闭 Hero 自动追击；
4. 接入路径代价（风险 + 距离）与传送；
5. 完成血包安全条件与大禹鼎/视野之灵动作。
