# 临时清兵路线与野怪奖励修复

实现时间：2026-11-02

## 一、临时清兵不再进塔射程

`HeroAI._try_temp_clear()` 增加路线安全检查：

- 候选敌方小兵本身不能在无掩护的敌方塔下；
- 用 `PathFinder.find_path()` 计算英雄到小兵的实际路径；
- 路径上任意点若进入敌方塔攻击范围 +1m，直接跳过该小兵；
- 只选择“目标安全 + 整条路线安全”的小兵。

这样临时清兵不会为了追兵穿过敌方防御塔。

## 二、野怪经验/金币只给同队

问题根因：

- `distribute_experience()` / `distribute_gold()` 原先把 `source.team` 传给 `_get_nearby_heroes()`；
- `_get_nearby_heroes()` 的语义是“排除该队”，所以野怪（中立队）被击杀时会把奖励发给所有附近英雄，甚至包含敌方。

修复：

- `_get_nearby_heroes()` 增加 `same_team` 参数；
- 野怪击杀时：
  - 奖励队伍 = `killer.team`；
  - 只收集击杀者同队的附近英雄；
  - 击杀者不是英雄时不给经验/金币；
- 小兵/防御塔等普通单位保持原逻辑，避免影响既有经济。

## 三、验证

- `battle.tscn`、`net_client.tscn`、`replay.tscn`、`lobby.tscn` 均 `ERRS=0`；
- 3 个固定种子基准无脚本错误；
- 3 种子初步数据：
  - 总 CS：66–72
  - 总金币：20,356–21,962
  - 总死亡：13–16
  - 总塔伤：3,069–4,978
  - 打野经济：1,446–1,774

死亡仍偏高，但临时清兵不再出现明显的无掩护穿塔。
