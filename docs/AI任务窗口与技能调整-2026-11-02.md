# AI 任务窗口 / 目标技能 / 追击逃跑消耗调整

实现时间：2026-11-02

## 一、改动

### 1. 接任务后的承诺窗口

- `AiConfig.TASK_COMMIT_WINDOW = 4.0` 秒；
- HeroAI 接受任务后，4 秒内不接其他任务；
- 窗口结束后，只有新任务目标明显更近时才切换；
- 任务完成/过期后 `team_task` 为空，可立即接新任务。

### 2. 不对非目标乱放技能

- `SkillTactics.try_best_combo()` / `use_best_skill()` 增加目标有效性校验；
- 技能候选增加施法距离过滤（`cast_range` 为世界距离，不是 ×0.01）；
- `HeroAI._try_use_skills()` 先检查目标存活/有效。

### 3. 优先接受更近的任务

- `assign_team_task()` 计算当前任务与新任务目标距离；
- 承诺窗口过后，若新任务目标没有明显更近，则保留当前任务。

### 4. 追击时远程消耗

- 追击逻辑不再只在 `SKILL_USE_RANGE` 内放技能；
- 改为调用技能层，由 `SkillTactics` 按每个技能的 `cast_range` 判断；
- 追击途中能用远程技能继续消耗。

### 5. 逃跑时远程消耗

- RETREAT / RECALL_SAFE 状态增加 `_try_flee_poke()`；
- 锁定最近敌人，调用 `use_best_skill()`；
- 目标无效、射程外或正在回城/传送时不放。

## 二、10 种子结果

| 指标 | 调整前 | 调整后 | 变化 |
|---|---:|---:|---:|
| 全队总 CS | 45.0 | 45.0 | 0% |
| 全队总金币 | 17,843 | 17,853 | +0.1% |
| 全队总击杀 | 3.0 | 5.0 | **+66.7%** |
| 全队总死亡 | 8.0 | 10.0 | +25.0% |
| 对英雄伤害 | 20,490 | 27,711 | **+35.2%** |
| 全队总塔伤 | 8,822 | 8,069 | -8.5% |
| 打野经济 | 2,811 | 2,254 | -19.8% |

判断：

- 对英雄伤害、击杀明显上升，说明追击/逃跑远程消耗生效；
- 但死亡 +25%、塔伤 -8.5%、打野经济 -20%，整体不是正向收益；
- 技能距离修正本身是正确修复（之前 `cast_range` 被错误 ×0.01，导致技能几乎不放）。

## 三、结论

这轮小调整**没有证明能提升整体指标**，更像行为约束修正：

- 不再对射程外目标空放技能；
- 接任务后不再立刻被新任务打断；
- 追击/逃跑有远程技能消耗；
- 逃跑施法增加了“贴脸/极残不放”的安全限制，死亡从 +50% 降到 +25%。

下一步建议：

1. 承诺窗口缩短到 2 秒，或只锁“同优先级任务”；
2. 追击技能只允许远程伤害技能，不允许控制/近战技能；
3. 打野任务与本地刷野重新对齐，恢复打野经济。
