# AI 任务窗口 / 目标技能 / 追击逃跑消耗调整

实现时间：2026-11-02

## 一、改动

### 1. 接任务后的承诺窗口

- `AiConfig.TASK_COMMIT_WINDOW = 2.0` 秒；
- HeroAI 接受任务后，2 秒内不接其他任务；
- 窗口结束后，只有新任务目标明显更近时才切换；
- 任务完成/过期后 `team_task` 为空，可立即接新任务。

### 2. 不对非目标乱放技能

- `SkillTactics.try_best_combo()` / `use_best_skill()` 增加目标有效性校验；
- 技能候选增加施法距离过滤（`cast_range` 为世界距离，不是 ×0.01）；
- `HeroAI._try_use_skills()` 先检查目标存活/有效。

### 3. 优先接受更近的任务

- `assign_team_task()` 计算当前任务与新任务目标距离；
- 承诺窗口过后，若新任务目标没有明显更近，则保留当前任务。

### 4. 追击时远程消耗

- 追击逻辑只在追击/逃跑场景调用 `use_ranged_damage_skill()`；
- 只允许：有伤害、有施法距离、非位移类（type != 4）的技能；
- 不再放控制/治疗/近战技能。

### 5. 逃跑时远程消耗

- RETREAT / RECALL_SAFE 状态增加 `_try_flee_poke()`；
- 锁定最近敌人，只调用 `use_ranged_damage_skill()`；
- 敌人贴脸 ≤4m 或自身血量 <30% 时不放，避免前摇送命。

## 二、10 种子结果

| 指标 | 调整前 | 调整后 | 变化 |
|---|---:|---:|---:|
| 全队总 CS | 45.0 | 45.0 | 0% |
| 全队总金币 | 17,843 | 18,044 | +1.1% |
| 全队总击杀 | 3.0 | 4.0 | +33.3% |
| 全队总死亡 | 8.0 | 10.0 | +25.0% |
| 对英雄伤害 | 20,490 | 19,656 | -4.1% |
| 全队总塔伤 | 8,822 | 9,124 | +3.4% |
| 打野经济 | 2,811 | 2,689 | -4.3% |

判断：

- 2 秒承诺窗口 + 只放远程伤害技能后，塔伤和打野经济恢复；
- 但死亡仍 +25%、伤害略降，整体仍不是明确正收益；
- 技能距离修正本身是正确修复（之前 `cast_range` 被错误 ×0.01，导致技能几乎不放）。

## 三、结论

这轮调整完成了 P1/P2：

- 承诺窗口从 4 秒缩短到 2 秒；
- 追击/逃跑只放远程伤害技能，不再放控制/治疗/近战技能；
- 对射程外目标不再空放技能。

指标上塔伤/打野恢复，但死亡仍偏高，下一步应做 P3：把打野任务与本地刷野重新对齐，并继续压缩死亡。
